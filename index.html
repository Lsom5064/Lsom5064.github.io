Current research · Human–AI interaction

VibeFactory

From an idea to an Android app.
Through conversation and visual edits.

I’m developing a system that helps people without programming experience create and refine native Android apps. Users describe what they need, attach reference images, and mark changes directly on an interface preview.

How the system works ↓
  • Kotlin / XML
  • Python / FastAPI
  • Codex CLI
01

A mobile workspace

An Android host app brings together conversations, image attachments, build progress, and APK downloads.

02

Visual, iterative refinement

Users mark elements to delete, move, change, or add. Sketches and explanations accompany follow-up requests.

03

Generation to delivery

A server coordinates Codex CLI, checks and builds Kotlin/XML projects, and preserves revisions for later updates.

Digital health · Published research

Connected eye-patch monitoring

A mobile app and clinician dashboard for monitoring patch-treatment adherence. BLE sensor readings are sent to the server every 15 seconds and presented through calendars and charts.

Accessibility · Research project

Understanding screen-reader navigation

A four-week study with 11 blind smartphone users, combining real-world interaction logs and interviews. Sequence mining and heuristics help identify recurring navigation inefficiencies.

  • Screen readers
  • Sequence mining
  • Field study

Focus: initial focus placement, non-interactive elements, and reverse-order navigation.
